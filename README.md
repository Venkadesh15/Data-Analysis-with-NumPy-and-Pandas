# 📊 Data Analysis with NumPy and Pandas

## 📌 Project Overview

This project focuses on learning and implementing fundamental Python data analysis techniques using **NumPy** and **Pandas**. It covers numerical computations, array manipulation, Series operations, and DataFrame analysis through practical examples involving temperature data, student marks, and sales transactions.

## 🎯 Project Objectives

- Understand NumPy arrays and perform numerical computations.
- Create and manipulate Pandas Series and DataFrames.
- Apply indexing, slicing, filtering, and conditional operations.
- Perform statistical analysis and aggregation using Pandas.
- Develop practical Python skills for data analysis.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Libraries:** NumPy, Pandas
- **IDE:** Visual Studio Code (VS Code)

## 📚 Project Structure

### 1. NumPy Array Operations

- Import NumPy and Pandas libraries.
- Create 1D and 2D NumPy arrays.
- Explore array shape, data type, and size.
- Convert Celsius temperatures into Fahrenheit.
- Calculate maximum, minimum, and mean temperatures.
- Perform array indexing and slicing operations.

### 2. Pandas Series Operations

- Create a Pandas Series with custom indexes.
- Display and access Series elements.
- Perform indexing and slicing using `iloc`.
- Apply conditional filtering.
- Update and delete Series elements.
- Calculate CGPA from student marks.

### 3. Pandas DataFrame Operations

- Create a DataFrame using transaction data.
- Display the first five rows.
- Explore DataFrame shape, columns, and data types.
- Select specific columns.
- Perform row and column slicing.
- Filter transactions based on multiple conditions.
- Calculate category frequency counts.
- Identify unique regional values.
- Calculate average transaction amounts by region.
- Update transaction values.
- Create and remove columns.
- Delete specific transaction records.

## 📂 Dataset Information

This project uses three sample datasets created directly in Python.

| Dataset | Description |
|---|---|
| Temperature Data | Daily temperature records for two weeks |
| Student Marks | Student marks and CGPA calculations |
| Transaction Data | Product categories, regions, and transaction amounts |
